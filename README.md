# SV Cope — рыбалка в Латвии

PWA-приложение (React + TypeScript + Vite), которое помогает понять, где, когда
и на что ловить рыбу в Латвии — на основе погоды, давления, фаз луны и карты
водоёмов.

## Статус

Реализованы все 6 этапов из плана: карта водоёмов, погода и давление, индекс
активности рыбы, база видов рыб, календарь клёва, светлая/тёмная тема,
локализация RU/LV/EN и дневник рыбалки.

## Возможности

- **Карта водоёмов Латвии** (Leaflet + Overpass API) — 10 000+ озёр и рек с
  названиями, поиск, фильтр озеро/река, кластеризация маркеров
- **Погода и давление** (Open-Meteo) — текущие условия, график давления за
  3 дня назад / 3 дня вперёд, явный тренд (растёт/падает/стабильно)
- **Индекс активности рыбы** (0–100) — составной, с настраиваемыми весами
  (давление, луна, время суток, температура, ветер, сезон), с разбивкой по
  факторам
- **База видов рыб** — щука, окунь, судак, лещ, плотва, карп, линь, угорь;
  топ-3 вида под текущие условия с приманками и снастями
- **Календарь клёва на 7 дней** — фазы луны, лучший час и лучшие дни недели
- **Дневник рыбалки** — учёт уловов (дата, место, вид, вес, условия) в
  localStorage, с автоподстановкой погодных условий при записи из карточки
  водоёма
- **Тёмная тема по умолчанию** с переключением на светлую, локализация
  RU/LV/EN, PWA (устанавливается на телефон, работает офлайн для статики)

## Структура проекта

```
рыбалка софт/
├── frontend/   React + TypeScript + Vite + Tailwind CSS
└── backend/    Node + Express, кэширует запросы к Overpass/Open-Meteo
```

Внутри `frontend/src` код разбит по модулям: `map/`, `weather/`,
`fishActivityIndex/`, `species/`, `calendar/`, `diary/`, `i18n/`, `context/`.

## Технологии

- **Frontend:** React, TypeScript, Vite, Tailwind CSS 4, Leaflet
  (react-leaflet + react-leaflet-cluster), suncalc, PWA (vite-plugin-pwa)
- **Backend:** Node.js, Express, кэш в памяти + на диске (TTL) для Overpass и
  Open-Meteo
- **Данные:**
  - [Open-Meteo](https://open-meteo.com/) — погода и давление, без ключа
  - [Overpass API](https://overpass-api.de/) (OpenStreetMap) — озёра и реки
    Латвии, без ключа
  - [suncalc](https://github.com/mourner/suncalc) — фазы луны, восход/закат,
    считается локально, без внешнего API

## Запуск

Понадобятся два терминала — backend и frontend запускаются отдельно.

### Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

Backend поднимется на `http://localhost:4000`. Первый запрос к
`/api/waterbodies` может занять 30–60 секунд — в это время backend тянет
данные о всех озёрах и реках Латвии из Overpass API и кладёт их в кэш (в
памяти и на диск в `backend/.cache/`, по умолчанию на 24 часа, см.
`OVERPASS_CACHE_TTL_HOURS`). Дисковый кэш переживает перезапуск сервера.

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Frontend поднимется на `http://localhost:5173` и будет проксировать запросы
`/api/*` на backend (см. `vite.config.ts`).

## Переменные окружения

### `backend/.env.example`

| Переменная                 | Назначение                                              |
| --------------------------- | -------------------------------------------------------- |
| `PORT`                      | порт backend API (по умолчанию 4000)                     |
| `ALLOWED_ORIGIN`             | разрешённый origin для CORS                              |
| `OVERPASS_URL`               | URL Overpass API                                          |
| `OVERPASS_CACHE_TTL_HOURS`   | сколько часов кэшировать список водоёмов                  |
| `OPEN_METEO_URL`             | URL Open-Meteo API                                        |
| `WEATHER_CACHE_TTL_HOURS`    | сколько часов кэшировать погодные данные                  |

### `frontend/.env.example`

| Переменная            | Назначение                                    |
| ----------------------- | ----------------------------------------------- |
| `VITE_API_BASE_URL`     | базовый URL backend API (по умолчанию `/api`)  |

Ключи API не нужны — Open-Meteo и Overpass бесплатны и не требуют
регистрации.

## API backend

- `GET /api/health` — проверка живости сервера
- `GET /api/waterbodies` — лёгкий список всех именованных озёр и рек Латвии
  (id, название, тип, координаты центра) — для отрисовки маркеров на карте
- `GET /api/waterbodies/:osmType/:osmId` — полная геометрия одного водоёма
  (запрашивается по клику на маркер, чтобы не тянуть ~30 МБ геометрии сразу)
- `GET /api/weather?lat=&lon=` — почасовая погода на 3 дня назад / 4 дня
  вперёд (Open-Meteo), кэшируется по округлённым координатам

## Калибровка индекса активности рыбы

Веса факторов заданы явно в
[`frontend/src/fishActivityIndex/config.ts`](frontend/src/fishActivityIndex/config.ts)
и в [`frontend/src/species/scoreSpecies.ts`](frontend/src/species/scoreSpecies.ts)
(веса пригодности вида под условия) — это первое место для правок при
калибровке по данным дневника уловов.
